✨ The Experience
This is a personal portfolio for Himanshu Kumar, a full-stack developer and MCA student. It uses a black-and-white visual system, cinematic loading sequence, subtle motion, and clean content sections to present skills, selected projects, résumé, and contact information.
The goal is simple: make the work easy to explore and the developer easy to remember.
🚀 Highlights & Features
🎬 Cinematic loading screen — animated progress, status messages, and a polished entrance.
🖤 Monochrome visual identity — dark surfaces, crisp typography, fine borders, and atmospheric background details.
📱 Responsive navigation — compact navigation with a mobile menu.
🌊 Motion and scroll effects — reveal animations, active-section navigation, and scroll progress.
👨‍💻 Developer profile — introduction, background, and focus areas.
🧰 Skills and tools — grouped capability sections for easier browsing.
🏆 Featured projects — a dedicated space to showcase selected work.
📄 Résumé section — includes a résumé asset from the project.
🔗 Contact and social links — clear paths to connect.
⚙️ Performance-conscious behavior — reduced-motion support and lighter effects for touch/low-capability devices.

🚀 Getting Started
🟢 Option 1 — Open Directly
Download or clone this repository.
Keep index.html, style.css, script.js, and the assets folder together.
Open index.html in a modern browser.
🔵 Option 2 — Use VS Code
Open the project folder in VS Code.
Open index.html with the Live Server extension.
Your browser will launch the portfolio on a local development URL.
Using a local server is recommended while developing, especially when testing on different devices.

🎨 Make It Your Own
Update text and sections: edit index.html.
Change colors and appearance: edit the CSS variables near the top of style.css.
Adjust animations and interactions: edit script.js.
Replace profile image: replace assets/profile.jpg while keeping the same filename, or update its path in the HTML.
Replace résumé: replace assets/resume.jpg and check the résumé section in index.html.
Update social links: search index.html for the GitHub and LinkedIn URLs and replace them with your own.
Tip: Keep asset paths and filenames in sync. If you rename a file without updating its references, the image or résumé may stop appearing.
📱 Responsive Design & Accessibility
The JavaScript checks the user's reduced-motion preference and adapts some visual effects for smaller or touch-based devices. Still, test the portfolio on your own phone and desktop after making changes—especially the menu, image loading, résumé section, and contact links.
