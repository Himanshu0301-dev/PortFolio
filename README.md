✨ About the Project

Himanshu Kumar's Digital Portfolio is a personal website designed to showcase my developer profile, technical skills, projects, résumé, and contact information through a cinematic monochrome aesthetic.

Built with HTML5, CSS3, and vanilla JavaScript, the portfolio combines minimalist design, smooth interactions, responsive layouts, and motion-led details to create a memorable browsing experience.

The goal: Make the work easy to explore, the experience enjoyable, and the developer easy to remember.

🚀 Key Features

- 🎬 Cinematic Loading Experience — animated progress indicators, status messages, and an engaging entrance.
- 🖤 Monochrome Design System — dark surfaces, crisp typography, subtle borders, and atmospheric visual details.
- 📱 Responsive Navigation — mobile-friendly navigation and an adaptable menu.
- 🌊 Scroll Animations — reveal effects, active-section navigation, and scroll progress indicators.
- 👨‍💻 Developer Introduction — a dedicated section for my background, interests, and development goals.
- 🧰 Skills & Technologies — organized sections highlighting technical skills and tools.
- 🏆 Featured Projects — a space to present selected projects and demonstrate practical experience.
- 📄 Résumé Section — a dedicated area for résumé content.
- 🔗 Social & Contact Links — convenient ways to explore my work and connect with me.
- ♿ Accessibility Considerations — reduced-motion support and responsive behavior designed to improve usability.

⚙️ Getting Started

Option 1: Run Locally

1. Clone the repository:
   
   git clone https://github.com/Himanshu0301-dev/PortFolio.git

2. Open the project folder:
   
   cd PortFolio

3. Open "index.html" in your browser.

Option 2: Run with VS Code

1. Open the project folder in Visual Studio Code.
2. Install the Live Server extension if you don't already have it.
3. Right-click "index.html".
4. Select Open with Live Server.

Your portfolio will open at a local development URL in your browser.

📱 Responsive Design & Accessibility

The portfolio is intended to provide a consistent experience across desktop, tablet, and mobile screens.

Accessibility and usability considerations include:

- Responsive layouts for different screen sizes.
- Reduced-motion preferences where supported by the implementation.
- Clear navigation and readable typography.
- Touch-friendly interaction patterns.

Always test the final website on multiple screen sizes and verify that navigation, images, résumé content, and contact links work correctly.
